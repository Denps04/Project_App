## 가산점 B — 나만의 AI 활용 기법

> **출처**: `03-qna-prep.md` Q24 — "본인만의 AI 활용 기법이 있나요? (가산점 B 기회)"

### 신청 예정 기법

#### 기법 1: CLAUDE.md 기반 규칙 주도 개발
- **내용**: `CLAUDE.md`에 아키텍처 규칙, 디자인 원칙, 코드 컨벤션을 명시해두고
  Claude Code가 매 작업마다 이를 자동으로 참조하게 함
- **효과**: 매 프롬프트마다 규칙을 반복하지 않아도 일관성 유지
- **증거**: `CLAUDE.md` 파일 + 생성된 코드의 일관성

#### 기법 2: 단계 분리 프롬프트 (Plan → Build → Verify)
- **내용**: 한 번에 구현 요청하지 않고 ① 계획 확인 → ② 구현 → ③ 검수 3단계로 분리
- **효과**: AI의 잘못된 방향을 초기에 잡아 재작업 최소화
- **증거**: `claude-code-prompts.md`의 STEP 구조

#### 기법 3: 비즈니스 규칙 선 명세 후 구현
- **내용**: UseCase 구현 전 "결석 한도 = 총 수업 × 0.25, 지각 3회 = 결석 1회" 등
  규칙을 텍스트로 명시한 뒤 코드 생성 요청
- **효과**: AI가 규칙을 잘못 해석하는 경우 방지
- **증거**: `calculate_attendance_limit.dart` 주석 + 테스트 코드
