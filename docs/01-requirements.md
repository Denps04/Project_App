# 01 — 요구사항 (MoSCoW)

## 사용자 시나리오

### 시나리오 1 — 학기 시작 첫 날
> 김대학 씨는 새 학기 시작일에 앱을 열어 5개 과목을 시간표에 등록한다.
> 교수명, 강의실, 색상을 지정하고 학사일정(개강, 중간고사, 기말고사)도 함께 등록한다.
> 홈 화면에서 오늘 수업과 이번 주 일정이 한눈에 보임을 확인한다.

### 시나리오 2 — 결석 위기 상황
> 김대학 씨는 알고리즘 수업을 3번째 결석했다.
> 결석 탭을 열자 빨간 경고 배지가 뜨고 "결석 한도 초과 위험"이 표시된다.
> 남은 결석 가능 횟수가 0임을 보고 이후 수업은 반드시 출석하기로 결정한다.

### 시나리오 3 — 기말 과제 마감 직전
> 김대학 씨는 과제 탭을 열어 이번 주 마감인 과제 3개를 확인한다.
> D-1인 과제가 빨간색으로 강조 표시되어 있고, 홈 화면 상단에도 나타난다.
> 과제를 완료 체크하자 목록에서 사라지고 완료 탭으로 이동한다.

## MoSCoW 요구사항

### ✅ Must (반드시 구현)

| # | 기능 | 설명 |
|---|---|---|
| M1 | 시간표 등록/조회/삭제 | 요일·시간·색상 포함 |
| M2 | 학사일정 캘린더 | 날짜 선택 + 카테고리(학사/시험/휴일/기타) |
| M3 | 결석 한도 자동 계산 | 총 수업 × 25% 한도, 지각 3회 = 결석 1회 |
| M4 | GPA 자동 계산 | 등급별 환산점수 × 학점 가중 평균 |
| M5 | 과제 메모 + 마감일 | D-Day 표시, 완료 체크 |
| M6 | 홈 화면 요약 | 오늘 수업 + 임박 과제 + 이번 주 일정 |
| M7 | 로컬 저장 | 서버 없이 오프라인 동작 |

### 🔵 Should (가능하면 구현)

| # | 기능 | 설명 |
|---|---|---|
| S1 | 다크모드 | 시스템 설정 연동 |
