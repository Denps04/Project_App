# 00 — 비전 & 목표

## 한 줄 가치 제안

> 흩어진 학사 정보를 손바닥 위에서 하나로 — 대학생 전용 올인원 학사 관리 앱

---

## 문제 정의

대학생은 매 학기 아래의 도구들을 동시에 사용한다.

| 정보 | 현재 쓰는 도구 | 문제 |
|---|---|---|
| 시간표 | 에브리타임, 종이 | 업데이트 번거로움 |
| 학사일정 | 학교 공식 사이트 | 매번 접속해야 함 |
| 결석 현황 | 머릿속, 메모장 | 한도 초과 인지 못함 |
| 학점 계산 | 엑셀, 계산기 | 수동 계산 오류 발생 |
| 과제 마감 | 카카오톡, 노션 | 알림 놓침 |

**핵심 문제**: 정보가 분산되어 있어 한 번에 파악이 불가능하다.

---

## 비전

대학생이 학사 관련 정보를 **하나의 앱**에서 등록·조회·계산할 수 있도록 한다.
서버 없이 로컬에서 동작하여 **언제 어디서나** 사용 가능하다.

---

## 목표 (7주)

| 주차 | 목표 |
|---|---|
| 10주차 | 기획·일정 문서 완성 |
| 11주차 | 설계·환경 구축, Hello World 빌드 |
| 12주차 | 핵심 기능 50% + 중간 발표 |
| 13주차 | 핵심 기능 100% + 테스트 |
| 14주차 | 마감·배포·문서 정리 |
| 15주차 | 최종 발표 |
